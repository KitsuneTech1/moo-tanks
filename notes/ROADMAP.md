# Roadmap

## M1: Playable Local Arena

- Completed first playable browser version.
- Working bots, upgrades, farming, scoring, minimap, and leaderboard are in place.

## M2: More Game Feel

- Add tank class choices at level milestones.
- Add twin, sniper, flank, machine gun, and drone-style builds.
- Add hit flashes, death bursts, level-up effects, and better audio.
- Tune bot skill tiers so easy bots farm and hard bots hunt.

## M3: Multiplayer Prototype

- Extract simulation rules from browser rendering.
- Add a Node WebSocket server with authoritative state.
- Add client prediction for the local tank.
- Add room creation and simple name entry.

## M4: Kitsune Flavor

- Original tank skins, faction colors, and boss shapes.
- Private lobbies for testing with friends.
- Optional account/score persistence after gameplay is worth keeping.
